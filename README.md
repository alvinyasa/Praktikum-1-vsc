## 🚀 Fitur Halaman Web

- **Foto Profil Bundar (Circular Avatar)**: Foto profil dipotong melingkar secara presisi dengan posisi wajah berada di tengah.
- **Glassmorphic & Responsive Design**: Tampilan modern yang menyesuaikan layar desktop maupun perangkat seluler.
- **Dark / Light Mode Toggle**: Fitur pengubah mode gelap dan terang.
- **Copy NIM Quick Button**: Tombol cepat untuk menyalin NIM ke clipboard dengan notifikasi toast.
- **Interactive Action Button**: Interaksi tombol sapaan.
